# הדס אפ! — אפליקציית Android

משחק בסגנון Heads Up עם מילים שקשורות להדס.

## התקנה

ה-APK נבנה אוטומטית ב-GitHub Actions בכל push ל-main.
הורדה ישירה בטלפון (הגרסה האחרונה):
https://github.com/oriadudai/hadas-up/releases/latest/download/HadasUp.apk

## איך משחקים

- מצמידים את הטלפון למצח, לרוחב, עם המסך כלפי החברות.
- מטים למטה (מסך לרצפה) = נכון. מטים למעלה (מסך לתקרה) = דילוג.
- אחרי כל הטיה מחזירים את הטלפון למצח.
- אפשר גם להקיש: יד ימין = נכון, יד שמאל = דילוג.

## עריכת המילים

- בתוך האפליקציה: "עריכת מילים". הרשימה נשמרת בטלפון.
- לשינוי קבוע של רשימת ברירת המחדל: `DEFAULT_WORDS` בקובץ
  `app/src/main/assets/index.html`.

## כיוונון רגישות ההטיה

ב-`MainActivity.java`: `TILT` (כמה צריך להטות, ברירת מחדל 6.5) ו-`NEUTRAL`
(כמה ישר הטלפון צריך לחזור, ברירת מחדל 3.0). ערכים ביחידות m/s², כש-9.8 = מסך אופקי לגמרי.
